# lachetquentin.github.io

Portfolio de Quentin Poullain, concepteur développeur C#, JavaScript et SQL : projets, parcours, compétences et contact.

En ligne : <https://lachetquentin.github.io/>

## Contenu

- `index.html` : la page unique, en français
- `assets/css/style.css` : styles, thème clair et sombre selon le réglage du système
- `assets/js/main.js` : améliorations facultatives (frise du parcours à jour, section active dans le menu)
- `assets/img/` : captures d'Admissions Hub et image de partage
- `assets/favicon.svg` : monogramme QP

## Aperçu local

Aucune compilation ni dépendance : ouvrir `index.html` dans un navigateur suffit.
Pour servir le dossier comme sur GitHub Pages :

```bash
python -m http.server 8000
```

puis <http://localhost:8000>.

## Publication

GitHub Pages sert la branche par défaut à la racine du dépôt. Tous les chemins sont relatifs.
